# 最终优化方向与验收标准

> 本文是“一次性把方向和验收说清”的冻结版。之后不再逐步加功能，
> 只按下面的 Gate 补证据；未过 Gate 的结果不进入最终结论。

## 1. 最终优化方向（只做四件事）

```text
A. 自研 tracer：exit pupil + 固定参考球根 + rayoptics 逐点对齐
B. CalculiX：真实 36 点 whiffletree/接触 + 0/90° 网格收敛
C. POPPY：pupil/OTF 统一，只做外部对照，不接核心
D. 桌面：Tkinter/Qt 启动器 + PyInstaller EXE + 原生文件接口
```

不再新增算法分支；四条线全部过 Gate 后，才写“最终报告”。

## 2. 状态标签（所有图/表/文档必须带）

| 标签 | 含义 | 可用于 |
|---|---|---|
| `CORE-VERIFIED` | 自研核心算法，有独立验证 | 主相位差/控制结果 |
| `SYNTHETIC-VALIDATED` | 合成数据闭环验证 | 模块1/2演示 |
| `EXTERNAL-CHECK` | 外部工具独立对照 | rayoptics/POPPY 对比 |
| `FEA-PROVISIONAL` | 简化/近似 FEA | 方案趋势，不是设计定型 |
| `TRACER-EXPERIMENTAL` | 自研 tracer 未对齐 | 内部调试 |
| `GUI-BETA` | 可运行桌面壳，未做安装包签名 | 演示/本地使用 |
| `UNVERIFIED` | 没有足够证据 | 不得写结论 |

## 3. 验收 Gate

### A. 自研 tracer

必须：

1. 用正确 **exit pupil 平面**，不是 M2 表面；
2. chief 固定，参考球根不跳根；
3. 对 5 个控制量、至少 3 个 field，与 rayoptics 逐点 OPD 对比；
4. 主导项 S 相对误差 ≤10%，无 1e8 nm 异常；
5. 输出 `tracer_compare.csv` + 日志 + ZMX sha256。

通过标签：`TRACER-REF-VERIFIED`。  
当前：**未通过**（fixed-plane 仍与 rayoptics 差 2–65 倍）。

### B. CalculiX

必须：

1. 真实 36 点 whiffletree 或接触，不是弹性地基；
2. 0°/90° 两个工况；
3. 两套网格（至少 1.5× 节点）RMS 差 ≤5%；
4. 接触/弹簧收敛、反力/位移合理；
5. 与设计锚点 6.4873/23.199 nm 对照，但不得把简化模型当整机验证。

通过标签：`FEA-WHIFFLE-VERIFIED`。  
当前：分布式弹簧 **FEA-PROVISIONAL**：0° 3.23 nm、90° 8.90 nm，网格差 <0.5 nm；但**不是真实 whiffletree/接触**。

### C. POPPY

必须：

1. 统一 pupil 网格、遮拦、像素/OTF 采样；
2. 比较径向 MTF/OTF，而不是只比 FWHM；
3. PD 只用外部 PSF 做偏差检查，不进入核心；
4. 输出 `poppy_otf_compare.json`。

通过标签：`EXTERNAL-CHECK-PASS`。  
当前：**未通过**（FWHM 76.4 vs 21.5 px；重采样后 PD 仍到边界）。

### D. 桌面

必须：

1. `--self-test` 通过；
2. 原生 FITS/ZMX/FEA CSV 文件对话框；
3. 离线可用，不需要 WSL/终端；
4. EXE 与 `_internal` 同目录可运行；
5. 文档说明 onedir、权限、依赖。

通过标签：`GUI-BETA`。  
当前：**通过 BETA**。

## 5. 最终报告写法

必须分栏：

```text
已验证（CORE/SYNTHETIC）
外部对照（EXTERNAL）
近似/暂定（PROVISIONAL）
未验证（UNVERIFIED）
```

不得把：

- 弹性地基写成 whiffletree；
- rayoptics 写成 Zemax；
- POPPY PD 写成核心精度；
- 合成数据写成实测；
- 桌面 BETA 写成正式发布。

## 6. 完成定义

项目“可交付”不是“所有数据真实”，而是：

1. 主算法有独立验证；
2. 每个数字有来源/标签；
3. 失败项明确写失败；
4. 桌面可启动、可复现；
5. CI 绿、文档一致。

当前完成度：

```text
主算法/合成闭环   ✅
外部对照         ⚠️
真实 FEA/Zemax   ❌
真实多离焦       ❌
桌面 EXE         ✅ BETA
```
