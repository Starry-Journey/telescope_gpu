## 2. 关键契约

| 契约 | 位置 | 说明 |
|---|---|---|
| 帧/观测 | `products/ccd/model.py` | 星空 → PSF(含视宁度) → 探测器链(泊松/读出/饱和/坏像元/宇宙线) |
| 前向模型 | `products/optics/forward.py` | `forward_psf_numpy(coeff, defocus, terms=...)`；3 项默认逐位不变 |
| 反演 | `products/pd/service.py` | `invert_psf(psf, defocus, terms=None)`，3 或 6 项 |
| 灵敏度矩阵 | `products/control/service.py` | `sensitivity(source="auto"/"proxy"/"zemax")`，响应带 source/label |
| 实测标定 | `products/sensitivity/measured.py` | 括阻位姿 + PD 反演 + 漂移消除 + `compare_with_zemax()` |
| 可观测性 | `products/sensitivity/observability.py` | 阈值降维 + 像散装调方案 |
| 工况注册 | `data/fea_cases/manifest.json` | id/口径/遮拦/RMS/Zernike/label/model |
| 任务协议 | `desktop/protocol.py` | job 信封 schema=1，`build_worker_command` |

## 3. 数据来源与标签

| 数据 | 产生方式 | 标签 |
|---|---|---|
| Zemax 3×5 S + 适用范围 | OpticStudio 2023 R1 ZOS-API（真实处方） | EXTERNAL-CHECK |
| Abaqus M1 板级 5 工况等 | Abaqus 2025 弹簧垫等效模型 | FEA-PROVISIONAL |
| Abaqus 设计版（OD2560/±5K） | 文档几何参数 + 假定支撑 | FEA-PROVISIONAL |
| CCD 合成帧 | 物理探测器链 | SYNTHETIC-VALIDATED |
| 实测 S | CCD+PD 台架 | UNVERIFIED（待台架） |
| M2 代理矩阵 | 3×5 占位 | UNVERIFIED |

## 4. 本轮（2026-11-20）新增/变更

- **CCD**：`products/ccd/model.py` 物理模型；`run_ccd_pipeline` 增加
  曝光/增益/读出噪声/暗流/天空背景/像元比例/视宁度/星密度/星等极限/饱和/
  位深/坏像元/宇宙线/抖动/快路径等参数；GUI ①页签新增"探测器/星空物理参数"面板。
- **ZMX 可视化**：`products/zemax/layout.py` 生成 2D 截面 + 3D 光路
  （真实模型：8 面、track 10812 mm、stop=2）；③A 页签显示两图并可导出。
- **FEA 可视化**：`fea_viz` 增加中心遮拦掩膜；新增 `fea_structure`
  渲染镜体几何 + 36/24 支撑点；③B 页签两个视图 + 导出。
- **Abaqus 设计版**：按紫台文档 OD 2560/ID 700/边厚 260/α=1e-7/±5 K 建 5 工况，
  注册进 manifest（22 个 case），限制见 `docs/紫台设计参数提取.md`。
- **GUI 稳健性**：导出 PNG/NPY/JSON 检查写入结果并回退到可写目录；
  窗口几何记忆；菜单栏；图片控件自适应缩放（修 3D 不显示）。
- **测试**：products 96、desktop 14、web 12、E2E 26 项全绿。

## 5. 已知限制

1. Abaqus 设计版为**平面环盘**（CAE `BaseSolidRevolve` 在本机 Abaqus 2025 上
   任何草图都报"实体旋转特征创建失败"，已记录），锥面矢高 ~106.6 mm 未建模；
2. 支撑布局（36+24）文档正文未给出，属假设；
3. Zemax 只覆盖 Z4/Z8/Z9、单视场 0.01°、波长 0.7 µm；
4. 3D 曲面视图覆盖节点凸包；中心遮拦已掩膜，外缘台阶仍按节点范围绘制。
