## 2. 端到端数据流水线（新采集链路）

一次完整观测/标定由 `products/pipeline/orchestrator.py`（`PipelineConfig` +
`WavefrontPipeline.run`）编排：

```text
高度角扫描（TelescopeTerminalApi）
  el = 15/30/45/60/75 deg
  每个高度角：goto_elevation(el) -> status() 确认 settled；必要时 goto_azimuth()
        │
        ▼
采集（CameraApi）
  capture(defocus_list=[-2,-1,0,1,2] waves, exposure_s)
  返回 raw ADU [5,N,N]；metadata() 带增益/读出噪声/暗流/位深/饱和/温度/时间戳
        │
        ▼
CCD 预处理（preprocess/ccd_calib.py）
  master bias/dark/flat -> 坏像元/饱和掩膜/宇宙线 -> 背景扣除
  -> 星点检测 -> 亚像素质心 -> 帧间配准 -> 归一化 PSF 栈 [5,n,n]
        │
        ▼
相位差反演（products/pd）
  z(el, u=0) = Z4/Z8/Z9（可扩展 6 项），含 cost/residual/nfev 质量门
        │
        ▼
实测灵敏度（products/sensitivity/measured）
  每位姿括阻式激励 ref -> +Δ -> ref -> -Δ -> ref（×R 轮）
  参考位姿线性插值消漂移 -> 中心差分/斜率拟合
  -> S(el)（行=Zernike 项，列=机构 DOF）+ rank/cond/nullspace/std
        │
        ▼
补偿表（products/control）
  u(el) = S(el)⁺ · z_target：Tikhonov 最小二乘 + 边界投影（最小范数解）
        │                                   │
        │ 可补偿项                          │ 不可补偿项（rank 不足/nullspace 方向）
        ▼                                   ▼
下发机构（MechanismApi）             FEA/装调请求（products/fea + 装调方案）
  逐个 DOF move + readback 确认         用 FEA 预判幅值、交叉验证、nullspace 先验
```

关键点：

- **高度角相关**：重力方向随 el 变化，S 是 el 的函数；补偿表按 el 存储/插值，
  不能拿一个 S 用到所有高度角；
- **数据质量门**：反演残差、饱和/坏帧、位姿未括阻（`unbracketed_poses`）都必须
  阻断该点，不能静默进入 S；
- **不可补偿项**：`rank < 目标项数` 的方向不允许用“大控制量硬凑”，交 FEA/装调；
- **mock 隔离**：没有真机时全部走 acquisition 的显式 mock（`mode="mock"`、
  `label="SYNTHETIC-VALIDATED"`），measured 结果保持 `UNVERIFIED`，
  不得写入报告结论。

## 3. 厂商必须提供什么（vendor 接口契约）

现状：**厂商尚未提供望远镜控制 API、相机 SDK、机构接口与工况数据**。因此
`products/acquisition/interfaces.py` 先固定抽象接口（`TelescopeTerminalApi` /
`CameraApi` / `MechanismApi` + `AcquisitionError`/`ApiTimeoutError`/
`HardwareError`），`products.acquisition.mock` 提供唯一可运行的显式 mock
（`mode="mock"`、`label="SYNTHETIC-VALIDATED"`）。真实 SDK 到位后只实现 adapter，
不改接口语义。方法名与单位以接口文件为准：

| 能力 | 接口方法（`products/acquisition/interfaces.py`） | 单位 / 量纲 | 时序要求 | 错误处理 |
|---|---|---|---|---|
| 终端状态/遥测 | `TelescopeTerminalApi.status()` | `connected/state/elevation_deg/azimuth_deg/settled/timestamp/limits/servo/operating_condition` | 每次状态带真实时间戳 | `NOT_CONNECTED`/`DEVICE_FAULT` |
| 指向/高度角扫描 | `goto_elevation(deg, timeout_s)`、`goto_azimuth(deg, timeout_s)` | deg（仰角 `[0,90]`、方位 `[0,360)`） | 阻塞到“到位 + settle”才返回；超时抛 `ApiTimeoutError` | 越限 `ValueError`；超时 `TIMEOUT`；`OUT_OF_RANGE` |
| 当前指向 | `pointing()` | `elevation_deg/azimuth_deg/ra_deg/dec_deg/epoch`（J2000） | 必须来自编码器/星表解算，不能回显指令 | 缺字段即报错，不猜值 |
| 相机拍摄 | `CameraApi.capture(defocus_list, exposure_s)` | raw ADU `[K,N,N]`；离焦=等效 Z4 波前波数 | 一个完整读出周期后返回；帧序与 `defocus_list` 一致 | `TIMEOUT`/`NOT_CONNECTED`/`DEVICE_FAULT`；饱和打标 |
| 相机元数据 | `CameraApi.metadata()` | `shape/bit_depth/adu_max/adu_gain_e_per_adu/read_noise_e/readout_bias_adu/dark_current_e_per_s/exposure_s/defocus/units/mode/label` | 与最近一次拍摄一致 | 缺必需字段→上层拒绝使用 |
| 机构 DOF | `MechanismApi.dofs()` | 每 DOF：`name/unit/low/high/step/home`（mm/mrad/deg/K） | 顺序即 S 矩阵列顺序 | 非法 DOF 定义直接报错 |
| 机构运动 | `MechanismApi.move(name, value)`、`home()` | 用 DOF 声明单位；`readback()` 为实测值 | 阻塞到“到位 + settle”；home 后 readback=home 值 | 越界 `ValueError`、未知 DOF `KeyError`、`HOMING_FAILED`/`DEVICE_FAULT` |
| 位姿回读 | `readback()` | 同 DOF 单位 + 时间戳（由上层对齐） | 与相机帧时间戳对齐（目标 ≤10 ms） | 缺时间戳→该位姿不用于 S |
| 工况数据 | `status()["operating_condition"]` | 温度 °C、重力方向 deg、支撑/装调状态 | 按采样时刻对齐 | 终端不提供时必须 `None` + `reason`，允许“无工况”但不能伪造 |

所有接口返回 dict 必须可 JSON 序列化，manifest 会原样记录；`units` 字段给出
units-of-record。`mode`/`label` 由实现提供（真实 adapter = `hardware`，
mock = `mock` + `SYNTHETIC-VALIDATED`），上层据此决定能否出结论。

## 4. 关键契约

| 契约 | 位置 | 说明 |
|---|---|---|
| 任务信封 | `desktop/protocol.py` | `schema_version=1`；`build_worker_command` 源码/冻结两种命令 |
| CCD 帧/观测 | `products/ccd/model.py` | 星空 → PSF（含视宁度）→ 探测器链（泊松/读出/饱和/坏像元/宇宙线） |
| 前向模型 | `products/optics/forward.py` | `forward_psf_numpy(coeff, defocus, terms=...)`；3 项默认逐位不变 |
| 反演 | `products/pd/service.py` | `invert_psf(psf, defocus, terms=None)`，3 或 6 项 |
| 灵敏度矩阵 | `products/control/service.py` | `sensitivity(source="auto"/"proxy"/"zemax")`，响应带 source/label |
| 实测标定 | `products/sensitivity/measured.py` | 括阻位姿 + PD 反演 + 漂移消除 + `compare_with_zemax()` |
| 可观测性 | `products/sensitivity/observability.py` | 阈值降维 + 像散装调方案 |
| 仪器常量 | `products/instrument.py` | M1 半径/遮拦/波长/默认离焦/PSF 尺寸，禁止散落魔法数 |
| 工况注册 | `data/fea_cases/manifest.json` | id/口径/遮拦/RMS/Zernike/label/model |
| 作业队列 | `products/jobs/store.py` | SQLite：submit/get/list/claim/complete/fail（Windows 下及时 close） |

## 6. 本轮（2026-11-20）变更

- **新增采集/预处理/编排三段**：products/acquisition（厂商接口 + 显式 mock）、
  products/preprocess（master 帧/坏像元/宇宙线/背景/星点/亚像素质心/配准）、
  products/pipeline/orchestrator.py（高度角扫描 → 采集 → 预处理 → PD → 实测 S
  → 补偿表 → FEA/装调请求）；
- **Web 路径下线**：Web 包的 UI/API 与服务 wrapper 删除；桌面不再有任何 Web 依赖；
  相关文档移入 `docs/archive/legacy-web/`；
- **文档重构**：`docs/README.md` 成为唯一索引；每个代码模块新增 README；
  `docs/代码模块注释索引.md` 删除已不存在的 C++/framework 行、补产品层模块；
- **保留**：`products/` 服务层接口（worker 任务名、返回字段）不变，
  Qt 页签与 `desktop/` 任务协议不变；数值结果（`0.001667λ` 合成基线、
  Zemax/Abaqus 实测数据）不重算。

## 7. 已知限制

1. 没有望远镜控制 API、相机 SDK、机构接口与工况数据，采集链只能跑显式 mock；
2. Abaqus 设计版为**平面环盘**（CAE `BaseSolidRevolve` 在本机 Abaqus 2025 报
   “实体旋转特征创建失败”），锥面矢高 ~106.6 mm 未建模；
3. 支撑布局（36+24）文档正文未给出，属假设；
4. Zemax 只覆盖 Z4/Z8/Z9、单视场 0.01°、波长 0.7 µm；
5. 实测 S 的台架流程（幅值扫描、位姿日志、时序握手）仍为 UNVERIFIED；
6. 3D 曲面视图覆盖节点凸包；中心遮拦已掩膜，外缘台阶仍按节点范围绘制。
