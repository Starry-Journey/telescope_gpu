# 实测灵敏度矩阵标定设计（CCD + 相位多样性）

状态：**SYNTHETIC-VALIDATED**（合成闭环证据齐备）；硬件流程 **UNVERIFIED**（待台架）
关联：[后续优化方向](后续优化方向.md) P4 · `desktop/gui.py` 页签③C · `desktop/worker.py` 任务 `sens_measure`/`sens_demo`

## 1. 定位：实测优先，FEA 降级为设计工具

S 的真值只能来自仪器自身响应：命令补偿机构按自由度做小幅已知运动，
用 CCD 拍帧 + 相位多样性反演得到每个位姿的 Zernike 系数，再对指令差分。
FEA 不再充当 S 的来源，只承担三个角色：

1. **实验设计**：用 FEA 预估 |S_ij| 选择激励幅值 Δu，使期望 Δz 高于 PD
   噪底、低于机构非线性区；
2. **交叉验证**：实测 S 与 FEA S 逐列相对差 → `EXTERNAL-CHECK` 报告；
3. **不可观测方向先验**：实测 rank < N 时，用 FEA 在 nullspace 方向做正则。

## 2. 测量协议

- 位姿序列（每自由度）：`ref(0) → +Δ → ref → −Δ → ref`（括阻式，
  每个激励位姿都被参考位姿夹住）；
- 每位姿采 5 帧离焦栈 `[-2,-1,0,1,2]`，与现有 PD 链完全一致；
- 整个序列重复 R 轮 → 每个矩阵元得到 repeatability std；
- 进阶：每自由度命令 ≥2 个幅值 → 斜率拟合 + 非线性残差指标；
- 幅值设计：`Δz ≈ S_fea·Δu ∈ [10σ_z, 非线性阈值]`。

## 3. 估计数学

- 每位姿 PD 反演 → `z(u) ∈ R^P`（当前 P=3：Z4/Z8/Z9；扩展 PD 状态即扩展行）；
- **漂移消除**：参考位姿 `z0(t)` 线性插值，`Δz = z − z0(t_u)`；
  括阻覆盖之外的位姿计入 `unbracketed_poses` 并告警；
- 单幅值：`S[:,j] = (Δz(+Δ) − Δz(−Δ)) / (2Δ)`（中心差分，偶次非线性自动消去）；
- 多幅值：带截距最小二乘斜率 + `nonlinearity` 残差指标；
- **迟滞**：`‖Δz(+) + Δz(−)‖ / ‖Δz(+) − Δz(−)‖`（偶分量占比）；
- SVD 诊断：rank / condition / nullspace 基向量，直接喂给
  `ControlSolver`（最小范数解天然只使用 range(S)）。

## 4. 精度预算（合成扫描，`diag` 2026-11-19，n=32）

| 每像素噪声(归一化 PSF) | maxeval | Δz 最大误差 | 单位姿耗时 |
|---|---|---|---|
| 0.0003 | 150 | ~0.011 waves | ~0.95 s |
| 0.001  | 300 | ~0.27 waves（噪底主导） | ~0.9 s |

结论：幅值必须按 PD 噪底 σ_z 设计；64×64 归一化 PSF 峰值能量密度更低，
同等每像素噪声对反演伤害更大（实测 0.42 waves）。
