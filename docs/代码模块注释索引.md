# 代码模块注释索引

> 本文件是“每个模块做什么、输入输出是什么、注释在哪里”的总表。
> C++/CUDA 源码使用文件头 + 函数前注释；Python 管线使用模块 docstring +
> 函数 docstring。行号会随代码演进漂移，以函数名为准。

## 1. 原有相位差反演模块（C++/CUDA）

| 文件 | 角色 | 关键接口 | 输入 → 输出 |
|---|---|---|---|

| `include/telescope/fft_cpu.hpp` / `src/fft_cpu.cpp` | radix-2 CPU FFT 参考实现 | `fft1d`、`fft2d` | 复数数组 → 频谱 |
| `include/telescope/cpu_reference.hpp` / `src/cpu_reference.cpp` | 逐像素 CPU 正向模型 | `make_psf_cpu`、`render_stars_cpu` | 光瞳/像差/星表 → PSF/星点图 |
| `include/telescope/fits_io.hpp` / `src/fits_io.cpp` | 最小 FITS 读写 + 元数据/星表卡片 | `write_fits`、`read_fits`、`write_star_cards` | 图像/头信息 → `.fits` |

| `include/telescope/phase_diversity.hpp` / `src/phase_diversity.cu` | 预处理、图像域 SSE、40 起点 + BOBYQA | `PhaseDiversitySolver`、`cost`、`solve` | 5 帧 FITS → Zernike 系数 |
| `apps/forward_generate.cu` | 生成带噪声 FITS 序列 | `main` | 配置 → `star_field_*.fits` |
| `apps/inverse_solve.cu` | 读 FITS、反演、写报告 | `main` | FITS → `inverse_result.txt` |
| `tests/test_*.cpp/.cu` | CPU/GPU 单元测试与交叉验证 | 自建 `TEST` 宏 | 断言 → CTest |

## 2. CCD 星场/运动目标管线（Python，本次新增）

| 文件 | 角色 | 关键接口 | 输入 → 输出 |
|---|---|---|---|
| `pipeline/config.py` | 类型化配置 | `SimConfig`、`PreprocessConfig`、`DetectConfig`、`AstrometryConfig`、`PipelineConfig` | JSON → dataclass |
| `pipeline/simulate.py` | CCD 序列 + 定标帧 + 星表 + 真值 | `make_wcs`、`distort_pixels`、`simulate_dataset` | `SimConfig` → raw FITS、bias/dark/flat、catalog/truth CSV |
| `pipeline/preprocess.py` | 暗场/平场/本底、mesh 背景、去噪 | `calibrate`、`estimate_background`、`denoise`、`preprocess_dataset` | raw FITS + 定标帧 → calibrated FITS/NPZ |
| `pipeline/detect.py` | 星点提取/质心、配准、帧差、形态学、Hough、轨迹 | `detect_stars`、`phase_cross_correlation`、`register_frames`、`hough_lines`、`detect_moving` | 帧栈 → 星表、候选、轨迹 |
| `pipeline/astrometry.py` | TAN WCS、三次畸变、球面匹配、迭代最小二乘 | `DistortionModel`、`match_sky`、`solve_astrometry`、`target_sky` | 星表 + WCS → 畸变系数、RA/Dec、残差 |
| `pipeline/evaluate.py` | 检测率/虚警率/位置/天体测量精度 | `match_by_frame`、`star_metrics`、`evaluate` | 真值 + 检测 → metrics/CSV |
| `pipeline/visualize.py` | 诊断图 | `fig_dataset`、`fig_stars`、`fig_moving`、`fig_astrometry`、`fig_metrics`、`fig_pipeline` | 结果 → PNG |
| `pipeline/run.py` | 命令行编排 | `main` | 配置 → 全套结果 |
| `pipeline/tests/test_core.py` | 几何/检测/端到端测试 | `unittest` | 断言 → OK/FAIL |

每个 Python 文件顶部都有“输入/输出/算法”docstring；关键函数有参数与返回
说明。管线数据流见 `pipeline/README.md` 和 Word 文档第 2 章。

## 4. 注释约定

- **C++**：文件头写模块职责；函数前写“做什么/参数/返回/异常”；GPU kernel
  额外写线程映射和共享内存使用；数值常量写物理单位。
- **Python**：模块 docstring 写数据流；公开函数写 NumPy 形状/单位；算法步骤
  用编号注释；配置项在 `config.py` 中写物理含义。
- **不要**在注释里重复代码字面意思；解释“为什么”和“边界条件”。

## 5. 已知缺口（后续可补）

- `pipeline/detect.py` 的 `star_centroid_box` 目前未用于局部窗口，而是对连通域
  整体加权；密集星场应改为局部窗口/PSF 拟合。
- `PreprocessConfig.bad_pixel_sigma` 已定义但未接入坏像素掩膜；当前用 sigma
  clip 背景抑制热像素。
- Hough 只验证直线 trail；曲线轨迹需要卡尔曼/多假设跟踪。
- 天体测量未接 Gaia 星表/大气折射；当前用仿真真值星表验证算法链路。
