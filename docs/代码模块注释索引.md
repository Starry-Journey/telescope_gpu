## 8. 注释约定

- **Python**：模块 docstring 写数据流/输入输出/单位；公开函数写参数/返回/异常；
  算法步骤编号；常量写物理单位；
- **C++**：文件头写模块职责；函数前写“做什么/参数/返回/异常”；kernel 写线程映射；
- **不要**在注释里重复代码字面意思；解释“为什么”和“边界条件”；
- 历史遗留注释里出现 web 或 FastAPI 字样时，以本索引与架构文档为准（Web 已删除）。
