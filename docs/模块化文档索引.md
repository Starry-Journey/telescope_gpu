## 1. 主技术报告与工程代码的关系

- 主报告正文：5 帧（0、±1、±2λ）、Z4/Z8/Z9、图像域 SSE、40 起点+坐标下降+top3 BOBYQA、maxeval=2000；
- 主求解器：`src/phase_diversity.cu`，结果 0.001667λ（45°）；
- 工程扩展：
  - `numerics/` 通用数值库；
  - `pipeline/` CCD 前端；
  - `ml/` 64×64 PSF 学习型代理（方法验证，不替代主求解器）；
  - `web/` 交互 demo。
- 详细对齐表见 `工程化技术说明_代码对齐版.docx` 第 1 章、`技术报告_代码对齐版_v2.docx` 附录 D。

## 2. 常用命令

```bash
# 数值库
cmake -S numerics -B build-numerics -DCMAKE_BUILD_TYPE=Release
cmake --build build-numerics -j4
ctest --test-dir build-numerics --output-on-failure

# CCD 管线
python3 -m pipeline.run --config configs/pipeline.json --force-sim
python3 -m pipeline.realistic --out data/realistic --frames 5 --stars 40

# 学习型反演
python3 -m ml.train_cnn --epochs 20 --samples 2048 --batch 64 --n 64
python3 -m ml.two_stage --samples 3 --starts 40 --maxeval 120

# Web
python3 -m uvicorn web.api.main:app --reload --port 8000
```

## 3. 文档口径

- **主报告**：0.001667λ 是波前 RMS（仿真）；
- **CCD**：0.85 是目标检测率；
- **ML**：34/1823 是 BOBYQA 评估次数；
- **Docker**：本机未构建成功（Docker Hub 超时），见 `Docker构建记录.md`。

不要把不同模块的数字放在同一张“精度表”里；每份文档都标注了网格/帧数/优化参数。
