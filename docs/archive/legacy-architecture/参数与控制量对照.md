# 参数与控制量对照（Module 3）

> 代码：`products/control/service.py`、`products/sensitivity/`、`framework/`
> 页面：`③ 框架`、`④ FEA 案例`
> 目的：把每个数字对应到物理量，避免把“代理矩阵”和“Zemax/FEA 真实灵敏度”混用。

## 1. 先分清三条 S

| 名称 | 输入 | 输出 | 当前状态 |
|---|---|---|---|
| **3A Zemax 运动学 S** | ZMX + `perturb.yaml` | ∂Z/∂(M2 5-DOF) | 待接 ZOS-API/ZMX parser |
| **3B FEA 环境 S** | M1 重力/热 FEA case | ∂Z/∂(θ,T) | 已跑通（合成参考面形） |
| **3C 代理 5-DOF S** | 3×5 线性 A | ∂Z/∂(M2 代理 DOF) | Web `③ 框架` 已跑通 |

三者不能互相替代。

## 2. `③ 框架` 面板参数

### 2.1 目标 `Z4 / Z8 / Z9`

- 单位：waves（λ=632.8 nm）；
- 物理意义：希望系统达到的低阶像差；
- 项目约定：`Z4` 离焦、`Z8` x 彗差、`Z9` y 彗差；
- 注意：项目 `Z8/Z9` 不是 Noll Z8/Z9；输出必须双标签。

### 2.2 差分步长 `δ`

```text
S[:,j] = (z(u_j+δ) - z(u_j-δ)) / (2δ)
```

- 单位：跟随控制量（mm 或 mrad）；
- 默认 `1e-3`；
- 太大：进入非线性区；太小：数值噪声/舍入；
- C++ `ControlAxis.step` 支持每个轴独立；Web v1 用一个全局 δ，后续应按轴配置。

### 2.3 Tikhonov `λ`

```text
min_u ||W(z_target - S u)||² + λ||u||²
```

- `λ=0`：纯最小二乘；3×5 欠定时取最小范数；
- `λ>0`：惩罚控制量幅值，解更“保守”，目标残差可能变大；
- 单位/量纲：`λ` 的量纲是 `target²/control²`，工程上按归一化后使用；
- 默认 `1e-8`，接近最小范数；不是物理约束。

### 2.4 S 矩阵

```text
S_ij = ∂z_i / ∂u_j
```

- 行：目标 `Z4/Z8/Z9`；
- 列：控制量；
- 单位：waves/mm、waves/mrad；
- 当前代理矩阵：

```text
          m2_focus  m2_decenter_x  m2_decenter_y  m2_tilt_x  m2_tilt_y
Z4          4.040       0.083          -0.083        0.976      -0.976
Z8          0.000      -4.633           0.000        0.000       0.000
Z9          0.000       0.000          -4.633        0.000       0.000
```

### 2.5 rank / condition / nullspace

- `rank=3`：只有 3 个独立目标方向；
- `nullspace=5-3=2`：存在 2 个控制组合不改变 3 个目标；
- `condition≈1.09`：行空间条件数好，但 **欠定** 仍导致 `u` 不唯一；
- 不要把“条件数小”误认为“控制量唯一”。

### 2.6 `u / S·u / residual / cost`

- `u`：5 个控制量，单位 mm/mrad；
- `S·u`：模型预测的目标；
- `residual = S·u - z_target`；
- `cost = Σ w² residual² + λ||u||²`；
- 3×5 时目标残差可以接近 0，但 `u≠truth` 是正常的。

## 3. 控制量与 M2 5-DOF 的对应

| 控制量 | 物理含义 | 单位 | 主要目标 | 真实 Zemax 实现 |
|---|---|---|---|---|
| `m2_focus` | M2 轴向调焦/镜间距 | mm | Z4 离焦 | 改变 M2 厚度/像面位置 |
| `m2_decenter_x` | M2 沿 x 平移 | mm | Z8 x 彗差 | M2 面 decenter x |
| `m2_decenter_y` | M2 沿 y 平移 | mm | Z9 y 彗差 | M2 面 decenter y |
| `m2_tilt_x` | M2 绕 x 倾斜 | mrad | 交叉项 | M2 面 tilt x；真实 Zemax 会先产生指向/像移 |
| `m2_tilt_y` | M2 绕 y 倾斜 | mrad | 交叉项 | M2 面 tilt y |

注意：

- 上表是 **3C 代理矩阵** 的对应；`m2_tilt_x/y` 与 Z4 的 ±0.976 交叉项是 synthetic 占位，不是 Zemax 实测；
- 3A 的 `perturb.yaml` 使用 `surface: 3`、`dof: decenter_x/decenter_y/tilt_x/tilt_y/focus`，接 ZOS-API 后应重新生成 S；
- `m2_focus` 的正负号取决于 Zemax 厚度/坐标定义，文档应同时给符号约定。

## 4. `④ FEA` 面板参数

### 4.1 工况

- `surface`：M1/M2/M3；
- `load_case`：重力方向（0°/90°）、热 ±20 K；
- `synthetic=true`：合成参考，不是已求解 FEA；
- `source_page`：设计资料页码，便于回溯。

### 4.2 几何与 RMS

- `aperture_radius_mm`：Zernike 归一化半径；
- `obscuration_ratio`：M1 中心遮拦（0.28）；
- `target_rms_nm`：设计资料的目标/文档值；
- `actual_rms_nm`：合成 map 在网格上的实际 RMS；
- 二者接近说明缩放正确；不是 FEA 收敛性证明。

### 4.3 面形 `dz_nm`

- 镜面法向位移，单位 nm；
- 显示为 `x_mm, y_mm, dz_nm`；
- 符号约定：沿镜面法向为正；代入 Zemax 时要注意镜面反射的 **2 倍光程**；
- 转 waves：`dz_nm / 632.8`。

### 4.4 Zernike 拟合

- 当前 15 项 Noll-like 基；
- 系数单位 nm；
- `Z1..Z15` 是基序号；工程标签 `j4→Z4`、`j7→Z9`、`j8→Z8`；
- `rms_nm`：输入面形总 RMS；
- `residual_rms_nm`：拟合残差；接近 0 说明 15 项足够表示当前合成 map；
- 66 项和刚体位移分离是下一阶段。

### 4.5 环境 S

```text
S_gravity = (z(90°) - z(0°)) / 90°   [waves/deg]
S_thermal = (z(+20K) - z(-20K)) / 40K [waves/K]
```

- 行：Z4/Z8/Z9；
- 列：`gravity_deg`（俯仰/重力方向）、`thermal_K`（ΔT）；
- 当前 `rank=2`、`condition≈23.07`；
- 热列接近零：合成热工况只有对称离焦，没有非对称项；
- **这不是 M2 5-DOF 控制灵敏度**。

## 5. 数值示例

当前 3C 默认：

```text
default_u = [0.05, 0.02, -0.01, 0.01, -0.02]
target = A @ default_u = [0.23377, -0.09266, 0.04633]
```

当前 3×5 的 `u` 是 **最小范数解**，不是 `default_u`；这是欠定系统的正常结果。

```text
Z4 = 4.149 nm；Z8/Z9 ≈ 0（合成 map 只有对称离焦）
```

## 6. 读图顺序

1. 先看 `synthetic`/`source`，确认不是实测；
2. 看 `rank/condition/nullspace`，判断系统是否可解；
3. 看 `residual`，判断目标是否达到；
4. 看 `u` 是否触及 bounds；
5. 最后才讨论 `u` 的物理含义；
6. 真实 Zemax/FEA 结果必须重新生成本文档中的表和 S。
