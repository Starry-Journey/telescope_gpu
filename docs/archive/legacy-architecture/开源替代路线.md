# 开源替代路线：ZMX、FEA、PSF

> 原则：不再修复/绕过破解 license。用学生版、学校 license 或开源工具；
> 真实数据必须来自可复现的合法计算/观测。

## 1. ZMX：rayoptics（首选）

`rayoptics` 有明确的 Zemax 读取模块：

```python
from rayoptics.zemax import zmxread
opt_model, info = zmxread.read_lens_file("2.5m主系统.ZMX")
```

- 文档：<https://ray-optics.readthedocs.io/en/latest/api/rayoptics.zemax.zmxread.html>
- 源码：<https://github.com/mjhoptics/ray-optics>
- 支持 UTF-16 ZMX（文档明确提到）；
- 可做 prescription 校验、real ray trace、paraxial/OPD 分析。

### 1.1 已验证结果（2026-11-17）

- Windows Python 3.13 安装 `rayoptics 0.9.10` 成功；
- `opticalglass.glassfactory` 首次导入约 14 s，随后可用；
- **关键修复**：`read_lens_file` 必须传 `pathlib.Path`，不能传 str；
- 已成功读取 `2.5m主系统.ZMX`：

```text
OpticalModel
8 surfaces
stop = 2
11 wavelengths
2 mirrors + 1 coordinate break
```

适配器：`products/zemax/rayoptics_adapter.py`。

### 1.2 下一步：从 prescription 到 S

```text
products/zemax/rayoptics_adapter.py  # 已能读 ZMX
  - 面型/stop/波长
  - 下一步 real ray trace
  - 有限差分 M2 decenter/tilt/focus -> OPD/ray aberration -> S
```

只在 adapter 成功读取后生成 S；读取失败就明确报错，不伪造。

### 1.3 合法 GUI 备选

- **Ansys Zemax OpticStudio Student Edition**：学生免费，可从 ZMX 导出 Zernike/CSV；
- 学校/实验室 license：正常启动后直接用现有 `scripts/zos_probe.ps1`。

## 2. FEA：CalculiX（首选开源）

**CalculiX** 是 Abaqus 输入风格的开放源码 FEA：

- 官网：<https://www.calculix.de/>
- 可用 `.inp`，和现有 Abaqus 简化模型脚本的结构接近；
- 适合环形镜/支撑/重力工况，能输出 `.frd/.dat`。

其他：

- **Code_Aster / Salome-Meca**：<https://www.code-aster.org/>
- **Elmer**：<https://www.csc.fi/web/elmer>
- **FEniCS**：适合自定义 PDE，不是 Abaqus 替代。

### 2.1 可复用模型

`scripts/abaqus_m1_simple.py` 的几何/支撑/重力设置可以转成 CalculiX `.inp`：

```text
annular disk OD 2500, ID 700, t 260
36 bottom supports (6-12-12-6)
24 side radial supports
gravity 0°/90°
output top-surface U3 -> CSV
```

### 2.2 合法 Abaqus 备选

- **SIMULIA Abaqus Student Edition**：免费但节点/规模有限，适合简化模型；
- 学校 license：启动合法 license server 后运行现有脚本。

## 3. PSF / 衍射传播

- **POPPY**：<https://poppy-optics.readthedocs.io/>，pupil→PSF、Zernike、离焦；
- **HCIPy**：<https://docs.hcipy.org/>，高对比度成像/波前传播；
- **prysm**：<https://prysm.readthedocs.io/>，光学传播/PSF。

用途：

- 用 rayoptics/CalculiX 得到真实 pupil/面形后，POPPY/HCIPy 做 PSF；
- 替代“只靠合成 Zernike”的模块 2 输入；
- 仍然不能替代真实多离焦观测。

## 4. 推荐执行顺序

| 顺序 | 工作 | 依赖 | 产出 |
|---:|---|---|---|
| 1 | rayoptics 读取 ZMX | `pip install rayoptics` | 面/stop/口径校验 |
| 2 | rayoptics 真实光线追迹 | 同上 | OPD/ray aberration |
| 3 | 有限差分 M2 5-DOF | 1–2 | 真实 3×5 S CSV |
| 4 | CalculiX 环形镜模型 | `ccx` | 0°/90° 面形 CSV |
| 5 | `/api/fea/upload` | 4 | 66 项 Zernike |
| 6 | 真实/半真实 PSF → 256² batch | 3/4/观测 | PD 验证 |

## 6. 工具形态：库、命令行、桌面 GUI

| 工具 | 形态 | 是否出现在桌面 | 启动方式 |
|---|---|---|---|
| rayoptics | Python 库，自带可选 Qt GUI | 否 | `rayoptics.exe` 或 `python -m rayoptics.qtgui` |
| POPPY/HCIPy | Python 库 | 否 | 只能 `import`/脚本调用 |
| CalculiX `ccx` | 独立命令行求解器 | 否（conda 环境内） | `conda run -n ccx ccx -i model.inp` |
| CalculiX `cgx` | 可选前后处理 GUI | 当前未安装 | 需额外安装 `calculix-cgx` |

### 6.1 为什么桌面没有图标

- rayoptics/POPPY 是 **pip 包**，不是桌面应用；安装位置在 Python site-packages；
- CalculiX 通过 **conda 环境 `ccx`** 安装，`ccx.exe` 在：
  `C:\Users\17424\miniconda3\envs\ccx\Library\bin\ccx.exe`；
- conda 不会自动创建开始菜单/桌面快捷方式。

### 6.2 启动命令

```powershell
# CalculiX 求解器
conda run -n ccx ccx -i data\fea_cases\calculix\m1_0deg

# rayoptics 可选 GUI
C:\Users\17424\AppData\Roaming\Python\Python313\Scripts\rayoptics.exe

# POPPY 没有 GUI，只能脚本
py -3.13 scripts\poppy_psf.py --n 256
```

**关键区别**：

- CalculiX 是**独立可执行求解器**，有自己的输入/输出格式；
- rayoptics/POPPY 是**库**，由我们的 Python 代码调用；
- rayoptics 的 Qt GUI 只是其附带的可视化前端，不改变它是库的事实；
- CalculiX 若要 GUI，需要 `cgx`，不是 `ccx` 自带。
