## 03 科学原理

> 这一章只讲主链路和扩展模块共用的物理/数学，不重复报告全文。


### 3.1 相位差法的成像模型

光瞳复振幅为 P(u,v)=A(u,v)·exp[i2πφ(u,v)]，焦面复振幅是傅里叶变换 U=F{P}，PSF=|U|²。对第 i 帧，在光瞳上加已知离焦 d_i：

φ_i(u,v) = Σ_k c_k Z_k(u,v) + d_i·Z4(u,v)

5 帧 d_i = 0、±1、±2λ 提供相位多样性；同一组 c 必须同时解释 5 帧。主项目用 8 个 Zernike 槽位，但只拟合 Z4/Z8/Z9；其余置零。


### 3.2 Zernike 与编号

Z4 是离焦，Z8/Z9 是 x/y 彗差。必须注意：本项目的 Z9 **不是** Noll Z9；Noll Z9 是 trefoil。工程标签与 Noll 的对应见报告表 C-1 和 `docs/代码模块注释索引.md`。

*表 3-1  工程标签与 Noll 编号（与报告附录 C 一致）*

| 工程标签 | 物理含义 | 真实 Noll | 是否拟合 |
|---|---|---|---|
| Z4 | 离焦 | Noll Z4 | 是 |
| Z5 | 45° 像散 | Noll Z5 | 否 |
| Z6 | 0° 像散 | Noll Z6 | 否 |
| Z8 | 彗差 x | Noll Z8 | 是 |
| Z9 | 彗差 y | Noll Z7 | 是 |


### 3.3 图像域 SSE 与优化

主项目代价函数：

J(c) = Σ_i Σ_p [ d_i(p) − m_i(p;c) ]²

其中 d_i 是预处理后的实测/仿真帧，m_i 是模型帧。主报告使用 **逐帧归一化** 后的图像域 SSE；不是 Gonsalves 频域消元。优化流程：

- 40 个随机起点（对称边界，允许负 Z9）；
- 坐标下降粗搜，步长 0.3 开始，不改进就减半，直到 1e-4；
- 前 3 名送 NLopt BOBYQA，`maxeval=2000`，`ftol=1e-10`，`xtol=1e-6`；
- 诊断：`cost(true)` 是模型自洽下界，`cost(zero)` 衡量非线性；最终代价低于 true 超过 1% 报警。

### 4.2 算法与复杂度

*表 4-2  算法/复杂度/失败模式*

| 算法 | 做法 | 复杂度 | 失败模式 |
|---|---|---|---|
| 线性方程组 | 部分主元 LU | O(N³) | 非方阵/奇异 → 异常 |
| 最小二乘 | 列主元 Householder QR | O(MN²) | 秩亏 → 用 SVD 版本 |
| 最小二乘 SVD | Thin SVD | 更慢 | 病态/秩亏更稳 |
| FFT | radix-2 Cooley–Tukey | O(N log N) | 非 2 的幂 → 异常 |
| RK4 | 经典四阶 | O(steps) | 负步长/倒序时间 → 异常 |

为什么不用正规方程？`AᵀA` 会把条件数平方，舍入放大；QR/SVD 更稳。为什么 FFT 只支持 2 的幂？radix-2 分治要求；非 2 的幂可补零/Bluestein，但不在本库范围。

### 5.4 运动目标检测

配准用“高斯高通 + 互相关 + 抛物线亚像素”；纯相位相关在 512² 星场上会锁到噪声峰，这是实际修过的 bug。中值栈作为静止星场模板，残差经 σ=1 pixel 平滑、3σ 阈值、3×3 开/闭运算，再连通域 + Hough + 最近邻轨迹（≥5 帧）确认。

## 06 学习型相位反演

> CNN 给初值、BOBYQA 精修；重点是用评估次数证明省在哪。


### 6.1 可微前向模型

`ml/phase_torch.py` 用 PyTorch 实现 64×64 的相位差前向：圆孔光瞳、Z4/Z8/Z9、5 帧 d=[−2,−1,0,1,2]λ、FFT、2×2 binning。所有操作可微，可生成训练数据，也可作为 unrolled 优化的前向。

*代码 6-1  可微前向的核心；与主项目共享物理，但网格/星点不同。*

```cpp
mask, z4, z8, z9 = zernike_basis(fft_n, pupil_radius)
phase = 2*pi*(c4*z4 + c8*z8 + c9*z9 + d*z4)
pupil = mask * exp(1j*phase)
psf = |fftshift(fft2(pupil))|^2
psf = avg_pool2d(psf, oversample)
```

![图 6-1  CNN 验证误差随 epoch 下降；c8/c9 约 0.018 waves，c4 约 0.035 waves。](figs/fig_ml_training.png)

*图 6-1  CNN 验证误差随 epoch 下降；c8/c9 约 0.018 waves，c4 约 0.035 waves。*


### 6.2 CNN 结构

*表 6-1  ZernikeCNN（约 15 万参数）*

| 层 | 配置 | 输出 |
|---|---|---|
| 输入 | 5×64×64（5 帧） | — |
| Conv+ReLU+Pool | 16/32/64 通道，3×3 | 64×8×8 |
| Pool | AdaptiveAvgPool2d(4) | 64×4×4 |
| Head | Flatten→128→3 | (c4,c8,c9) |

训练：2048 个在线样本、batch 64、Adam 1e-3、CosineAnnealing、20 epochs；输入按帧峰值归一化，标签按量程归一化。噪声是每帧峰值的 1% 高斯；直接按 1.0 加噪声会淹没归一化 PSF，这是实际修过的 bug。


### 6.3 two-stage：34 vs 1823

固定同一个 NumPy 正向模型和同一个 NLopt `LN_BOBYQA`，只换初值：A 是 CNN 一次前向 + 一次 BOBYQA；B 是 40 个随机起点，每个跑一次 BOBYQA，取最好。

*表 6-2  3 个独立测试样本的 two-stage 结果（仿真）*

| 方法 | 平均评估次数 | 平均时间 | 波前 RMS 误差 |
|---|---|---|---|
| CNN + BOBYQA | 34 | 0.226 s | 0.00955 |
| 40 随机 + BOBYQA | 1823 | 13.33 s | 0.00955 |

![图 6-2  CNN 初值与 40 随机起点的 BOBYQA 评估次数/精度对比。](figs/fig_two_stage.png)

*图 6-2  CNN 初值与 40 随机起点的 BOBYQA 评估次数/精度对比。*

> **口径提醒**  
> 这只是方法验证：BOBYQA maxeval=120，baseline 是“40 起点 × BOBYQA”，不是主报告的“40 起点坐标下降 + 前 3 名 BOBYQA（maxeval=2000）”。34 vs 1823 说明“好初值省评估”，不能写成主项目已经节省 54×。


### 6.4 与主报告的关系

*表 6-3  主求解器与 ML 代理的差异（不能混表）*

| 项 | 主报告 | 本 ML 实验 |
|---|---|---|
| 网格 | 256×256，过采样 2（FFT 512²） | 64×64，过采样 2 |
| 星点 | 15 颗，星点叠加 | 纯 PSF，无星点 |

| 优化 | 40 起点 + 坐标下降 + top3 BOBYQA，maxeval=2000 | CNN 初值 + BOBYQA maxeval=120 |

*代码 7-1  反演接口；CNN 用峰值归一化，BOBYQA 用 sum 归一化。*

```cpp
@app.post("/api/invert")
def invert(req: SimRequest):
    stack = forward_stack(torch.tensor(truth), cfg, add_noise=True).numpy()
    cnn = model(peak_normalise(stack)) * scales
    x, nfev, cost = bobyqa(cnn, sum_normalise(stack))
    return {"truth": truth.tolist(), "cnn": cnn.tolist(),
            "refined": x.tolist(), "nfev": nfev, "cost": cost}
```
