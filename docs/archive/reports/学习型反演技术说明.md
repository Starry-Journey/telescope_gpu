## 02 可微前向

> 傅里叶光学 + Zernike，全部 torch 可微。

P=A·exp(i2πφ)，φ=Σc_kZ_k+d·Z4；PSF=|FFT(P)|²；2×2 binning。Z4=√3(2ρ²−1)，Z8=√8(3ρ³−2ρ)cosθ，Z9=√8(3ρ³−2ρ)sinθ。

*代码 2-1  前向核心。*

```cpp
mask,z4,z8,z9 = zernike_basis(fft_n)
phase = 2*pi*(c4*z4+c8*z8+c9*z9+d*z4)
psf = |fftshift(fft2(mask*exp(1j*phase)))|^2
```

噪声按每帧峰值相对缩放；直接加 1% 绝对噪声会淹没归一化 PSF（峰值 ~1/n²），这是实际修过的 bug。


### 2.2 采样与归一化

64×64 输出、2× 过采样（FFT 128²）、2×2 binning。归一化分三套：前向每帧 sum=1；CNN 输入按帧峰值；BOBYQA 目标按 sum。三套不能混，否则精度会无故下降。


### 2.3 为什么是 64×64

主报告是 256²/15 星/5 帧；训练 CNN 需要成千上万样本，256² 的 CPU 训练成本过高。64×64 纯 PSF 保留 Zernike/离焦/FFT 的物理，用于方法验证；结论不外推到主报告。

> **口径提醒**  
> two-stage 用 maxeval=120，baseline 是“40 起点×BOBYQA”，不是主报告的“坐标下降+top3”；不能写成主项目已节省 54×。


### 4.3 传统法的局部极小

c8/c9 有符号/多峰结构；从零起点常落到 c8≈0 的宽局部极小，16 个随机起点才稳定。CNN 的价值是给一个接近真值的初值，而不是保证全局最优；two-stage 仍需要代价/残差兜底。

### 附录A 关键源码

*代码 A-1  可微前向。*

```cpp
def psf_from_coeff(coeff, defocus, cfg):
    mask, z4, z8, z9 = zernike_basis(fft_n, cfg.pupil_radius)
    phase = 2*pi*(c4*z4 + c8*z8 + c9*z9 + defocus*z4)
    pupil = mask * torch.exp(1j*phase)
    psf = |fftshift(fft2(pupil))|**2
    return avg_pool2d(psf, cfg.oversample)
```

*代码 A-2  two-stage 对比的评估计数。*

# two_stage.py: same BOBYQA, different initial guess
