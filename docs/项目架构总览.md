# 项目架构总览（Qt 主路径）

> 这是当前目录/职责的权威入口，旧文档按此归档。

## 1. 主路径

```text
desktop/qt_app.py          薄入口（worker/GUI 分派）
desktop/gui.py             PySide6 窗口/页签
desktop/worker.py          无 Qt 服务 worker
  ├─ ① CCD/PSF             web.ccd_pipeline_service / fits_pipeline_service
  ├─ ② PD                  web.pd_service
  ├─ ③B FEA/66 项          products.sensitivity.service
  ├─ ③A ZMX                products.zemax.zmx_parser
  ├─ ③C S/控制             web.framework_service
  └─ ④ 演示                ml.traditional
```

桌面长任务用 **QProcess 子进程**：

```text
Qt -> [同一 EXE --worker task] -> JSON stdout
取消 -> QProcess.kill()（真正终止子进程）
```

## 2. 保留的核心层

```text
numerics/        LU/QR/SVD/FFT/RK4 + 测试/教学
framework/       数据/参数/模型/控制契约，C++ 参考实现
products/        ccd/io、pd/batch、sensitivity、zemax、fea
pipeline/        离线 CCD 参考/评估（CLI）
ml/              traditional forward + CNN 研究（非 Qt 必需）
data/            fea_cases、zemax S
docs/            文档
```

## 3. Web/React 的定位

```text
archive/legacy-web/ = 旧 web/ui、web/api、Tk/WebView 入口
web/*_service.py    = 兼容 wrapper（Qt 不再使用）
```

Qt 已覆盖主功能，Web 仅保留兼容；不再新增 Web 页面。
最终删除条件：

1. Qt 结果导出、日志、取消、FEA/PD/CCD 全部稳定；
2. 没有外部脚本依赖 `web.api`；
3. `docs` 中旧 Web 教程完成归档。

## 4. ml 的定位

- `ml/traditional.py`：Qt ④ 演示/传统 forward，保留；
- `ml/phase_torch.py`、`ml/dataset.py`、`ml/two_stage.py`、`ml/runs/*`：
  学习型反演/训练，**Qt 当前不依赖**；
- 保留条件：后续要用 CNN 初值/256² 加速；否则归档到 `archive/ml-research/`。

## 5. 核心性能/并行方向

- PD：多起点/4 worker/CNN top-3 已有；继续用子进程隔离；
- FEA：分布式弹簧并行；
- 数值库：保持 Eigen/FFT 基准，避免把 GUI 依赖塞进 numerics；
- Qt：长任务全部走 QProcess，禁止在 GUI 线程跑服务。

## 6. 最终目录目标

```text
desktop/        主 GUI
products/       CCD/PD/FEA/Zemax 产品服务
pipeline/       离线数据基准
numerics/       数值库/教学
framework/      契约/参考实现
data/           可复现数据
docs/           总览 + 模块文档 + 验收
archive/        legacy-web / ml-research（可选）
```

删除/归档前必须有过 Gate 记录；不要因为“目录简洁”删掉可复现数据或验收证据。
