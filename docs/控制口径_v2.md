## 2. 控制模型（v2）

```text
传感器（PD）:   离焦 CCD 5 帧  ──PD/BOBYQA──▶  a_PD = (Z4, Z8, Z9)  [waves @632.8nm, Noll 正交]
控制对象:       a = a0 + S_Z·u + ε            S_Z (3×5): M2 位姿 → 出瞳波前
指向:           θ = P·u                        P  (2×5): M2 位姿 → 像面指向
堆叠:           [a; θ] = [S_Z; P]·u = A·u      A (5×5)
背景:           + S_F·env（M1 重力/热变形项；M2 只能补偿其落在 range(S_Z) 内的分量）
解:             u = A⁻¹·[a_target; θ_target]   （A 满秩 → 唯一；边界用 lsq_linear）
```

## 3. 实测矩阵（EXTERNAL-CHECK，OpticStudio 2023 R1，真实处方，Δ=0.01）

S_Z（waves/(mm 或 mrad)）：

|  | focus | dec_x | dec_y | tilt_x | tilt_y |
|---|---|---|---|---|---|
| Z4 | **−23.284** | 0 | 0 | 0 | 0 |
| Z8 | 0 | **−1.656** | 0 | 0 | +1.387 |
| Z9 | 0 | 0 | **−1.656** | −1.387 | 0 |

像散证据行 S_astig（waves/unit）：**全零**（Z5/Z6 对 M2 所有自由度无响应）——
"M2 对像散全盲"的证据来自真实光学模型，不再引用 S_F。

指向 P（arcsec/(mm 或 mrad)，f_sys=20625 mm，主光线像点位移）：

|  | focus | dec_x | dec_y | tilt_x | tilt_y |
|---|---|---|---|---|---|
| θx | 0 | −1.118 | 0 | 0 | +0.986 |
| θy | 0 | 0 | −1.118 | −0.986 | 0 |

**堆叠 A=[S_Z; P] 5×5：rank=5，cond=1351.8，奇异值 [74.6, 74.6, 23.3, 0.055, 0.055]**
→ 5 个自由度全部可观，u 唯一（`control5()` 数值验证：u 恢复误差 3e-17）。
指向方向奇异值最小（0.055）→ 指向通道是弱观测方向，控制时注意权重。

## 4. 唯一性与最小范数（口径 5 与 6 的关系）

- 只有 S_Z（3×5）：u 有 2 维零空间，最小范数解只是**控制选择**，不是唯一物理位姿；
- 加 P 后（5×5）：零空间消失，u **物理唯一**；
- 若某执行器失效/受边界限制，退化回 3×5 语义时必须重新声明"最小范数选择"。

## 6. 验证标准（口径 8）

补偿效果验收 = 三件事同时看：

1. **残余波前**：补偿后 PSF/OPD 残差 RMS（waves @632.8nm）；
2. **指向残差**：θx/θy 残差（arcsec，激光测距收发一致性）；
3. **不可补偿项**：落在 M2 零空间（如 Z5/Z6）的背景分量 → FEA/装调清单。

`control5()` 响应中 `wavefront_residual_waves` 与 `pointing_residual_arcsec`
即为 (1)(2) 的直接输出。
