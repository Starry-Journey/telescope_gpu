## 1. 需求与结论

**需求**：S 不再用有限元"精确建模"，改为在仪器上用 CCD 图像测——
补偿机构按自由度运动产生 Zernike 相位差，差分得到灵敏度矩阵。

**结论**：已按此路线实现完整测量链并闭环验证。

```text
机构指令 u_j → CCD 5 帧离焦栈 → 相位多样性反演 z(u) → 参考位姿插值消漂移
→ 中心差分/斜率拟合 → S[:,j] → SVD(rank/cond/nullspace) → ControlSolver
```

FEA 角色调整（不再产 S）：

| 原角色 | 新角色 |
|---|---|
| S 的真值来源 | 实验设计：按 PD 噪底选激励幅值 Δu |
| —— | EXTERNAL-CHECK 交叉验证（实测 vs FEA 逐列相对差） |
| —— | nullspace 方向先验正则 |

## 2. 测量协议

**位姿序列（每自由度括阻式）**

```text
ref(0) → +Δ → ref → −Δ → ref        × R 轮 × N 个自由度
```

- 每个激励位姿都被参考位姿夹住 → 漂移可线性插值扣除；
- 每位姿采 5 帧 `[-2,-1,0,1,2]` 离焦栈，与既有 PD 链完全一致；
- 重复 R 轮 → 每个矩阵元得到 repeatability std；
- 进阶模式：每自由度 ≥2 个幅值 → 斜率拟合 + 非线性残差指标；
- 幅值设计：`Δz ≈ S_fea·Δu ∈ [10σ_z, 非线性阈值]`。

## 3. 估计数学

| 环节 | 公式/方法 |
|---|---|
| 漂移消除 | `Δz = z(t_u) − z0(t_u)`，`z0` 由前后参考位姿线性插值 |
| 单幅值差分 | `S[:,j] = (Δz(+Δ) − Δz(−Δ)) / (2Δ)`（偶次非线性自动消去） |
| 多幅值 | 带截距最小二乘斜率 + `nonlinearity` 残差 |
| 重复性 | 同水平重复的样本标准差，按 `√Σσ²/(2Δ)` 传播 |
| 迟滞 | `‖Δz(+) + Δz(−)‖ / ‖Δz(+) − Δz(−)‖`（偶分量占比） |
| 诊断 | SVD：rank / condition / nullspace 基向量 |
| 覆盖告警 | 括阻外位姿计入 `unbracketed_poses` 并置 warning |

| 每像素噪声（归一化 PSF） | maxeval | Δz 最大误差 | 单位姿耗时 |

## 6. 过程中发现并修复的缺陷

| 缺陷 | 现象 | 修复 |
|---|---|---|
| `terms=None` 覆盖默认值 | worker 任务 `TypeError: 'NoneType' is not iterable` | `measure_sensitivity` 内部归一化 `terms` |
